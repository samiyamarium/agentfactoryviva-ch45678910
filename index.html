Chapter 4: AI Prompting in 2026

13 Core Concepts, 80% Real AI Value & System Prompting Principles

I. Core Viva One-Liners (The 13 Key Concepts)

  • 1. Novice vs. Power User: A power-user prompt is a full operational briefing containing files, goals, limits, and exact asks.
  • 2. Training vs. Retrieval: AI learned by reading; strong where data is dense, prone to hallucination where internet data is thin.
  • 3. Search vs. Deep Research: Model answers stem from static weights, web retrieval, or multi-step reasoning depending on prompt phrasing.
  • 4. Context Window Invariant: The model is stateless; it knows strictly what is inside the current context window.
  • 5. Reasoning & Thinking Modes: Modern reasoning models execute multi-second thinking loops prior to output generation.
  • 6. Sycophancy & Rubrics: AI naturally leans toward agreeing with users; neutral instructions with a scored rubric remove bias.
  • 7. The Iteration Loop: High quality requires a 4-stage loop: Context input → Generation → Feedback → Expansion.
  • 8. Multimodal Processing: Ingestion of text, images, spreadsheets, and audio simultaneously with asymmetric strengths.
  • 9. Artifacts & Code Generation: Structured prompts generate interactive, self-contained web applications for instant preview.
  • 10. Verified Code Execution: Models run programmatic sandboxes for exact values; users must enforce verification.
  • 11. Desktop Apps & Permissions: Desktop agents execute file actions; always enforce the least privilege principle.
  • 12. Model Economics: Cost and latency vary heavily across modalities, requiring intelligent task routing.
  • 13. Multi-Model Consensus: Having competing models grade each other yields high-reliability signals without human intervention.

Chapter 6: Skills & Connectors Crash Course

Portable Instructions (SKILL.md) & Live App API Connectors

I. Core Viva One-Liners (Extending Capabilities)

  • Skills Definition: Reusable instruction packages (defined via SKILL.md) teaching AI *how* to perform a multi-step job.
  • Connectors Definition: Real-time authorization bridges giving AI read/write access to external app APIs (Drive, Slack, Notion).
  • Permission Inheritance: Connectors strictly inherit user privileges; AI cannot reach data the authenticated user cannot access.
  • Skill vs. Connector: A Connector represents access (what AI reaches); a Skill represents expertise (how AI executes).
